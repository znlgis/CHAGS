## 0. 一句话

**让孩子亲手把混沌掰开、撑住一万八千年、再把自己的身体一件件放进世界** ——
玩完之后，他抬头看到太阳会说：「那是盘古的左眼。」

---

## 1. 这个典故要让孩子记住什么

盘古和曹冲称象的"爽点"完全不同：
称象是**解题的聪明**，盘古是**创造的壮阔 + 把自己交出去的奉献**。

拆成三层，每层都要有一个可玩、可感的落点：

| 层 | 内容 | 孩子的记忆锚点 |
|---|---|---|
| ① 分离 | 天地混沌如鸡子，阳清为天，阴浊为地 | 「本来是一团的，要把它分开」 |
| ② 坚持 | 天日高一丈，地日厚一丈，盘古日长一丈，如此万八千岁 | 「要撑好久好久，久到一万八千年」 |
| ③ 化身 | 垂死化身：气成风云，眼为日月，血液为江河，毛发为草木 | **「太阳是左眼，月亮是右眼」** |

第 ③ 层是记忆的主力：神话最迷人的地方不是"分开了"，而是**世界的每一部分都是他**。

## 2. 玩法设计：五段式

沿用曹冲称象验证过的节奏 —— **少写字，多动手，每一段都对应原文一句话**。

### 第 0 段 · 开场（story 模板，约 15 秒）
两幕，一屏一句话，点哪都行：
1. 「很久很久以前，天和地还没有分开。」
2. 「宇宙像一个大鸡蛋，盘古睡在里面。」

### 第 1 段 · 开（游戏定制场景 chaos，约 15 秒）
- **画面**：一片黑暗里，一个半透明的"鸡蛋"缓缓起伏，里面有光点与暗块在搅动（混沌）。
- **动作**：**连点鸡蛋**。每点一次，蛋壳裂开一道纹、蛋身颤一下、音效变沉。
- **第 4 次点击**：蛋"轰"地炸开 —— 轻的东西（亮粒子）向上飞，重的东西（暗块）向下沉。
- **不讲道理**：画面自己说明"清升为天，浊降为地"。

> 这一段是**游戏定制代码**（约 100 行）。它不可复用，但正是架构里预留的"40% 定制"。

### 第 2 段 · 撑（grow 模板，约 40 秒）—— 核心体验
- **画面**：天压在头顶、地在脚下，中间夹着盘古。天和地一开始是贴在一起的。
- **动作**：**连点屏幕**。每点一次：天升高一丈、地下降一丈、**盘古长高一丈**（他真的在画面里被拉长）。
- **计数**：屏幕下方一个大数字往上跳：600 → 1200 → …… → **18000 年**。
  每次点击 = 600 年，约 30 次点满。
- **手感**：连点越快，天升得越顺（连击加成），但没有惩罚——停了也不会掉下去。
- **结束**：天成了（星空浮现），地成了（山峦成形），盘古高得顶天立地。

> 这一段对应原文「天日高一丈……如此万八千岁」，把"坚持"变成**手指的酸**，
> 而不是一句"要有毅力"。

### 第 3 段 · 化（place 模板，约 60 秒）—— 记忆主力
- **画面**：盘古缓缓躺下，身体化成 6 团光球，落在底部托盘里。
  世界里留出 6 个**空的轮廓**（太阳的圆盘是暗的、河道是干的、地面是秃的）。
- **动作**：把每团光**拖到它该去的地方**：

| 光球 | 归位处 | 归位瞬间 |
|---|---|---|
| 左眼 | 天上的空日轮 | 太阳点亮、金光四射 |
| 右眼 | 天上的空月牙 | 月亮升起、银光洒下 |
| 头发 | 天顶 | 满天星斗亮起 |
| 气息 | 天中 | 云卷风起，缓缓流动 |
| 血液 | 地上的干河道 | 江河奔流 |
| 汗毛 | 地上的秃地 | 草木生长 |

- **不许失败**：拿起某个光球时，**它该去的位置会轻轻发光**。
  孩子靠"形状 + 提示"完成配对，全程零文字。
- **反馈**：每归位一件，画面亮一分，并在该位置用**语音**说出原文
  （「左眼变成了太阳」）——用听，不用看。
- **全部归位**：整个世界亮起来，山川日月俱全。

> **关于"死"的处理（重要）**：不做任何死亡表现。
> 盘古是「躺下 → 化成光 → 光飞向世界」，配柔和的音效。
> 画面语言是"他变成了世界"，而不是"他死了"。

### 第 4 段 · 典故卡（reward 模板，约 15 秒）
- 标题、拼音、星星、一句话寓意、出处原文。
- 寓意建议：**「他把自己，变成了整个世界。」**
- 关键词：混沌 · 分开 · 化身

**总时长约 2.5–3 分钟**，落在既定的 3–5 分钟预算内。

## 3. 需要新增的能力（两个模板）

这是本次工作的主要工程量。两个模板都**为后续典故服务**，不是一次性投入：

### 3.1 grow 模板 —— "持续发力，让某件事长大"

| 关卡脚本字段 | 含义 |
|---|---|
| targetValue / step | 目标值 18000、每次点击 +600 |
| unitLabel | 计数单位（年 / 丈 / 里 / 块） |
| resistanceCurve | 进度曲线（越到后面每点涨幅略减 → 手感上有"越来越难"） |
| drawFigure | 游戏提供"被拉长的那个东西"怎么画（盘古 / 愚公 / 精卫） |

可复用典故：**愚公移山、精卫填海、铁杵磨针、闻鸡起舞、卧薪尝胆、悬梁刺股**。
（"坚持类"典故在成语里占比很高，这个模板的复用率会很高。）

### 3.2 place 模板 —— "把东西放到它该去的地方"

| 关卡脚本字段 | 含义 |
|---|---|
| slots[] | 每个位置：坐标、形状（太阳/月亮/河/树…）、归位后的动画类型 |
| orbs[] | 每个光球：坐标（托盘）、形状、正确的槽位 id、归位时的语音 |
| hintMode | 拿起即高亮目标槽位（默认开，保证零失败） |
| drawSlot / drawOrb | 游戏提供的画法（保证美术可控） |

可复用典故：**孔融让梨、完璧归赵、负荆请罪、司马光砸缸（选择正确做法）**，
以及所有"某物变成某物 / 某物归某处"的桥段。

### 3.3 chaos 场景 —— 游戏定制
只在 `games` 里实现，不进模板库。

## 4. 内容数据模型的变化：神话 ≠ 信史

现有 schema 假设"有朝代、有年代"（dynasty / era / yearApprox），
盘古属于**上古神话**，需要一处小改动：

```jsonc
{
  "kind": "myth",              // 新增：'history'（默认）| 'myth'
  "dynasty": "上古",
  "era": "上古·神话",
  "yearApprox": -9999,         // 仅用于历史长卷排序，让它落在最左端
  "source": {
    "book": "《三五历纪》",     // 三国·吴 徐整 整理的最早文字记录
    "quote": "天地混沌如鸡子，盘古生其中。万八千岁，天地开辟，阳清为天，阴浊为地。"
  }
}
```

- `kind` 让历史长卷可以把神话、传说、信史用不同底色区分（神话在最左端，视觉上"更远"）。
- 化身部分的原文出自《五运历年记》，用作游戏内语音与揭晓语，不额外占用卡片版面。

## 8. 风险与取舍

| 风险 | 对策 |
|---|---|
| 连点 30 次会不会手酸/枯燥 | 每次点击都有明确的视觉增长 + 音调递进 + 连击反馈；30 次约 20–30 秒。若实测偏累，方案里已留 `resistanceCurve` 可随时调成 20 次 |
| 6 个槽位在竖屏会不会挤 | 已按 750×1334 排出版面（天空 4 个 + 地面 2 个 + 底部托盘），先出图确认再定 |
| "盘古死了"对低龄玩家是否合适 | 全程不做死亡表现，改为"躺下 → 化成光 → 飞向世界"，配柔和音效 |
| 两个新模板摊薄了单个典故的完成度 | 两个模板都是高复用（坚持类 / 归位类各能覆盖 5+ 典故），且本次只做最小可用版本 |
| 神话放进"历史长卷"是否违和 | 用 `kind` 区分底色，神话落在最左端并标注"上古·神话"，反而形成"从神话到信史"的时间纵深 |
