# 三十六计 · 第一辑（胜战计 1–6）方案

> 依据：[三十六计方案.md](三十六计方案.md)（已确认按推荐执行）。
> 本辑交付 **第 1–6 计、6 个游戏、5 个新模板**，每计一个专属玩法。
> 验收：`pnpm verify` + `pnpm e2e`（本辑 6 条 autoplay 通关用例）全绿。

## 〇、本辑的硬约束（写代码前先看）

1. **模板只声明本辑真正实现的模式**（`siege` 只写 `vital`、`borrow` 只写 `force`、
   `stillness` 只写 `bide`、`window` 只写 `fire`）——后续批次再扩，避免留下跑不通的空壳。
2. **每个模板必须实现 `runAutoplay()`**：`?autoplay=1` 要能一局走完，
   否则这一计没有端到端验证（现有 17 部典故全靠它）。
3. **纯逻辑与画面分家**：判定写在 `*.logic.ts`（不 import Phaser），场景只负责画与手感，
   `*.logic.test.ts` 覆盖边界（可与 e2e 的坐标常量互查）。
4. **每个模板的常量放在自己的模板文件里**（如 `RUSE = {...}`），不挤进 `layout.ts`，
   这样新模板之间、与既有模板之间都不会互相踩。
5. **零惩罚**：被识破 / 白鼓 / 窗口关闭 → 退回与重来，不扣星、不结束。
6. **儿童化**：不出现死亡与流血；不出现"骗朋友"；`借刀杀人` 落在"借力"，
   `趁火打劫` 落在"看清时机"，没有任何"加害"的画面。
7. **引文口径**：逐字确证不了的史源原文**不编**，改用《三十六计》本计按语
   （`source.book = 《三十六计·X套》`），战例写进故事分幕与 `figures` / `era`。

## 一、五个新模板

### 1. `ruse` 示形 —— 瞒天过海（hide）、声东击西（divert）

**机制**：一条走廊，尽头是检查口（`gate`）。灯每隔 `lamp.intervalMs` 亮一次，亮之前 `warnMs` 有征兆。
灯亮时，**还没过关**的东西里，凡是"此刻被看到的"都会被退回原位（零惩罚）。

| 字段 | 说明 |
|---|---|
| `mode` | `hide`：靠外壳骗过检查（每件东西选对"该装成什么样"）；`divert`：靠时机（灯照哪一侧，另一侧才走得通） |
| `gate` | 检查口 `{x,y,radius}`：把东西拖过它就永久安全 |
| `items[]` | `{id, kind, x, y, disguiseAs?, shells[]}`，`shells` 是可选外壳 `{id, kind, x, y}` |
| `lamp` | `{intervalMs, warnMs}` |
| `gaze` | divert 用：`{left:{x,y}, right:{x,y}}` —— 灯照左 / 照右 |
| `noises[]` | divert 用：`{id, x, y, holdMs}` —— 敲锣，把灯留在左（这一侧）`holdMs` |
| `hint` | 卡住时的提示（≤24 字） |

**判定（`ruse.logic.ts`）**：`lampPhase(level, t)`、`gazeSide(level, t, noiseHold)`、
`isExposed(item)`（灯亮 + 被看到 + 外壳不对）、`isCarriedPast(level, item)`、
`isRuseComplete(level, passedIds)`。divert 模式下"被看到"就等于被退回（不吃外壳）。
**schema refine**：hide ⇒ 每件都必须有 `disguiseAs` 且 `shells` 里**恰好有一个** kind 与它相同（保证有解）；
divert ⇒ 必须有 `gaze`、至少一个 `noises`，且不允许 shells。

### 2. `siege` 要害 —— 围魏救赵（vital）

**机制**：正面 `front` 硬推推不动（每点一次只加一点点），另有 `vital` 要害：
点中要害后，对方的守备被抽走（`resistance` 下降），正面才推得动。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'vital'` |
| `front` | `{x, y, radius}` 正面 |
| `vital[]` | `{id, x, y, radius, relief}`，点一次阻力减 `relief`，点过就变"已回防" |
| `resistance` | 初始阻力（0–10） |
| `goal` | 正面推进到多少算解围 |

**判定**：`frontGain(resistance) = max(0.2, 1 - resistance / 10)`；
`relieve(level, state, vitalId)` 只在未点过时生效；
`isSiegeDone(level, progress)`。**必须验算**：光打正面（`resistance` 不降）到不了 `goal`，全点要害之后能到。

### 3. `borrow` 借力 —— 借刀杀人（force）

**机制**：重物 `load` 自己推不动（力气记在 `self` 上，很小）。画面里有支点与力源，
把绳子连上去，`power` 加起来够 `needed` 才能抬起。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'force'` |
| `load` | `{x, y, radius, weight}` |
| `props[]` | `{id, kind: 'self' | 'fulcrum' | 'source', x, y, radius, power}` |
| `needed` | 需要多少力 |

**判定**：`totalPower(level, connectedIds)`、`isLifted(level, connected)`、
`selfPower(level)`（必须 < `needed`，schema refine 保证）。连接可撤销（点已连的绳子解开）。

### 4. `stillness` 忍 —— 以逸待劳（bide）

**机制**：鼓一通接一通地响。**鼓响时出击 = 白费力气**（对方还有劲），
只有在最后一通鼓之后的窗口里出击才对。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'bide'` |
| `beats[]` | `{id, drumMs, windowMs, correct}`，按时间顺序；**恰好一个** `correct: true`（schema refine） |
| `action` | `{x, y, radius}` 出击按钮 |

**判定**：`phaseAt(level, t)` → `{beatId, phase: 'drum' | 'window' | 'rest'}`；
出动时机判定 `strikeAt(level, t)` → `'hit' | 'early' | 'idle'`；
`isStillnessDone(state)`。在 `correct: false` 的窗口出击记 `early`（白鼓一次，不惩罚），继续等下一通。

### 5. `window` 时机窗口 —— 趁火打劫（fire）

**机制**：对方的营地按周期在"稳"与"乱"之间摆：`calmMs` 里靠近就会被赶回来，
`windowMs` 里才能干活。每件活儿要点若干下（`workTapMs` 一下），窗口关上时没干完的活儿**进度清零**（零惩罚）。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'fire'` |
| `cycle` | `{calmMs, windowMs}` |
| `jobs[]` | `{id, x, y, radius, workMs}` |
| `workTapMs` | 点一下推进多少毫秒的活儿 |
| `goal` | 干完几件算成功（≤ jobs.length） |

**判定**：`phaseAt(level, t)` → `'calm' | 'warn' | 'window'`；
`tapJob(state, job, level)`、`closeWindow(state, level)`、`isWindowDone(level, state)`。

### 第 1 计 · 瞒天过海 `mantian-guohai`（模板 ruse · hide）

- 内容：`kind: strategy`，`stratagem: {number: 1, set: 1}`；pinyin `Mán tiān guò hǎi`；
  唐·贞观十九年（`yearApprox: 645`）；figures `['薛仁贵','唐太宗']`；
  `source`: 《三十六计·胜战计》/瞒天过海/`'备周则意怠，常见则不疑。阴在阳之内，不在阳之对。'`
- moral：`把大事藏在最平常的样子里：越显眼的东西，越要看着不起眼。`
- keywords `['平常的样子','藏','渡海']`；ageRange `[7,10]`
- 故事两幕：
  1. `s1` 三十万大军到了海边 —— "海浪太大，皇帝站在岸上不敢上船。"
     旁白讲唐朝大军到海边、风浪大、皇帝发愁。
  2. `s2` 海边多了一座"大营" —— "皇帝笑着走进大营，脚下的地一点也不晃。"
     旁白讲薛仁贵用彩布搭成大营、里面摆酒席，皇帝进去只觉稳当；帘子一掀，大营早漂在海上。
- keyMoment（beat `s2`）：问"要让皇帝不知不觉过海，把船装扮成什么？"
  选项：**大营**（canonical）/ 战舰 / 木筏；reveal："越平常的样子，越不容易让人起疑。"
- misconceptions：`['瞒天过海不是骗人，是把大事放进平常的样子里','不是所有事都靠力气大']`
- quiz：记忆题"薛仁贵把船装扮成了什么"（大营）；
  **迁移题**"要做一件很显眼的大事，哪种做法最像瞒天过海"（把它悄悄放进每天都会做的事里）。
- 关卡（ruse·hide）：3 件货（`drum` 大鼓 / `banner` 长旗 / `armor` 盔甲架），
  各 3 个外壳（`straw` 柴捆 / `sack` 米袋 / `net` 渔网），正确外壳 = 柴捆；
  `gate` 在右上 `(600, 430, 90)`；灯 `intervalMs: 5200, warnMs: 1200`。
- 画面：渡口的栈桥 + 一排货 + 一盏会扫过来的灯；通过闸口时货"上船"。
