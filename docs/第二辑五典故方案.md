## 0. 先说最大的风险：五个"动手"会不会又变成同一件事

现有七部游戏的动作是：**称**（等量代换）、**补**（形状配对）、**射**（瞄准）、**填**（连点）、**追**（长按）、**挖**（连点 + 交接）、**撑/化**（连点 + 拖光球）。
第二辑这五则，如果偷懒都用"连点涨进度"，做出来就是第六次换皮。

方案给每一则一个**只属于它的动词**，再给每一则一个**只属于它的签名画面**：

| 典故 | 动词 | 手感 | 签名画面（记忆锚点） |
|---|---|---|---|
| 神农尝百草 | **尝** | 拖到嘴边先尝一口，才知道该往哪块木牍上放 | 一排草药在木牍上亮起来 |
| 大禹治水 | **疏** | 手指在洪水上划出一条河道，水自己流走 | 三条河道把洪水引向东方，龙门山裂开 |
| 太公钓鱼 | **等** | 全程几乎不推进；点了诱惑就得多等一会儿 | 直钩悬在水上三尺，远处一辆车慢慢近了 |
| 烽火戏诸侯 | **点** | 点一次火，她笑一次；点到第三次，天边就空了 | 烽火一座座亮向天边，最后一次什么也没回来 |
| 杞人忧天 | **解** | 把"想明白"送到担忧上，泡泡一个个破掉 | 头顶的黑云散了，他在星光下睡着 |

**尝 / 疏 / 等 / 点 / 解** —— 没有一个和现有七部重样。

## 1. 这五则正好补上历史长卷的空档

现在馆里 7 则：上古神话（-9999 ~ -9994）→ 战国寓言（-320）→ 三国（210）。中间**从上古到战国的三千多年是空的**。
这五则落进去，长卷从"神话"一路走到"寓言"，年代连续了：

| 典故 | 年代 | 出处 | 一句话内核 | 孩子该记住的 |
|---|---|---|---|---|
| 神农尝百草 | 上古·传说（-2800） | 《淮南子·修务训》 | 他亲口尝百草，教人哪些能吃、哪些能治病 | **尝过才知道；有毒的也要记住** |
| 大禹治水 | 夏（-2070） | 《孟子·滕文公上》《史记·夏本纪》 | 堵不住，就给它一条流向大海的路 | **疏，不是堵** |
| 太公钓鱼 | 商末周初（-1050） | 《史记·齐太公世家》 | 直钩无饵，离水三尺 —— 他钓的不是鱼 | **等一个值得等的人** |
| 烽火戏诸侯 | 西周·末年（-771） | 《史记·周本纪》 | 烽火是给敌人用的，开玩笑开到没人来 | **信，用一次少一次** |
| 杞人忧天 | 战国·寓言（-350） | 《列子·天瑞》 | 天是气、地是土，想明白了就睡得着 | **怕，是因为还没想明白** |

## 2. 模板策略：3 个新模板 + 1 次复用 + 1 个专属场景

沿用已经验证过的做法：**模板只留"循环与判定"，画面全部外置**（tap 模板就是这么把精卫、夸父、愚公做得互不相干的）。

| 模板 | 用途 | 复用前景 |
|---|---|---|
| **`sort`（新）** 分类归位 + 先尝后分 | 神农尝百草 | 田忌赛马、对症下药等"辨别/归类"类典故 |
| **`trace`（新）** 手指划路、按顺序过锚点 | 大禹治水的"疏" | 都江堰、郑国渠、张骞通西域、郑和下西洋（画路线） |
| **`wait`（新）** 忍耐等待 + 诱惑回调 + 收束动作 | 太公钓鱼 | 苏武牧羊、卧薪尝胆、程门立雪 |
| `place`（复用） | 杞人忧天 | 已有两处先例（盘古化身、女娲补天） |
| 专属场景 `beacon` | 烽火戏诸侯 | 一次性机制，留在游戏包里（沿用盘古 `chaos` 场景的做法） |

### 2.1 `sort` —— 分类，而且要"先尝后分"

```ts
export const SortLevelSchema = z.object({
  bins:  z.array(SortBinSchema).min(2).max(4),   // 木牍：id / kind / x / y / radius / label
  items: z.array(SortItemSchema).min(4).max(10), // 草药：id / binId / kind / x / y / speak
  /** 可选：先尝后分。没有尝过的物件放到木牍上会被"请回去先尝一口"（零失败） */
  probe: z.object({ x: z.number(), y: z.number(), radius: z.number() }).optional(),
  hint: z.string().min(1).max(24),
});
```

- 判定只有一条纯函数：`binFor(item, bins)` + `isCorrect(item, bin)`；拿起来时正确的木牍发光（沿用 place 的零失败设计）。
- **`probe` 是这则典故的教学核心**：没尝过的草上是一个问号，尝过之后才有图标（甜 / 苦 / 麻 / 毒）。孩子必须自己尝，才知道往哪儿放。
- 单测：判定、高亮、进度、"没尝不能分"、autoplay 路径不卡死。

### 2.2 `trace` —— 手指划出来的河道

```ts
export const TraceLevelSchema = z.object({
  segments: z.array(TraceSegmentSchema).min(1).max(4), // 每段：start + anchors[]（3~4 个）+ end
  maxGap: z.number().positive(),   // 采样点之间的最大间距（防止"瞬移"作弊式连线）
  hint: z.string().min(1).max(24),
});
```

- 判定：**只看有没有按顺序经过锚点**（锚点半径 60+ 的容差），不做像素级比对，不要求线画得多直。
- 断了 / 划歪了：水停在原地打转，孩子接着划 —— **不判失败、不倒退**。
- 每过一段 → 水位降一格、露出的土地变绿 → 回调 `onSegmentDone`（大禹在这里插"三过家门"）。
- 单测：直线过锚点、只划一半、乱划不误判、越序不推进、采样稀疏（慢机器）也过、autoplay 直达。

### 2.3 `wait` —— 以"不推进"为玩法

```ts
export const WaitLevelSchema = z.object({
  durationMs: z.number().positive(),           // 等多久（autoplay 下自动缩短到 1/7）
  temptations: z.array(WaitTemptationSchema).max(4), // 换弯钩 / 加鱼饵 / 换地方
  penaltyCap: z.number().int().min(0).max(5),  // 诱惑最多把时间延后几次 —— 保证永远不会卡死
  lines: z.array(z.string().min(1)).max(6),    // 点老人时轮着说的话（双语可翻译）
  finale: z.object({ x: z.number(), y: z.number(), radius: z.number() }), // 收束动作：收起直钩
  hint: z.string().min(1).max(24),
});
```

- 计时**按墙钟（`services.now`）算，不累加帧 delta** —— 这是夸父那次的教训（CI 上按住 3.4 秒到不了 45%）。
- 诱惑不是惩罚，是"分心就得多等一会儿"：老人摇摇头、把弯钩收起来，日影退回一点；退满 `penaltyCap` 次之后只回应、不再延后。
- 单测：penalty 有上限、进度不为负、autoplay 缩短后能完成、反复点诱惑也不会永不完成。

### 2.4 为什么杞人用 `place`、烽火用专属场景

- **杞人忧天**：`place` 的语义就是"把东西放到它该去的地方" —— 这里是**把"想明白"送到担忧上，泡泡就破了**，判定是语义配对（气 ↔ 天塌、土 ↔ 地陷、日月 ↔ 日月会掉、小石子 ↔ 星星会坠）。四个槽位、四个光球，一次拖拽一次"看一看"的小演示，正好是 place 的形状。
- **烽火戏诸侯**：核心是"每点一次，世界对你的信任少一格"，是一个**叙事型的一次性机制**（点 → 接力传火 → 诸侯赶来 → 她笑 → 信任 -1 → 真的来了没人来）。硬塞进 tap 会把 tap 的循环拧变形；按盘古 `chaos` 的先例，做一个游戏专属场景更干净，也不污染模板库。

## 3. 五则逐个设计

### 3.1 神农尝百草（`shennong`，模板：`sort`，一屏）

- **故事两幕**：① 上古的人靠采野果、打猎过活，吃错了东西就生病，没有人知道哪种草能治病；② 神农挎着竹筐走进山里 —— 每一种草，他都亲口尝一尝。
- **keyMoment**（beatId s2）："草有没有毒，怎么才知道？" → 自己尝一口，记下来（canonical）
- **玩法**（一屏，约 60–90 秒）：
  - 上方神农，中间 6 株草，底部（或两侧）3 块木牍：**能吃**（麦穗）/ **能治病**（药碗）/ **有毒别吃**（叶子 + 叉）
  - **第一步 · 尝**：把草拖到神农嘴边 → 1 秒的品尝动画（叶子入口、表情变化、头上冒出图标：甜 / 苦 / 麻 / 有毒）；**尝过之后，草上才带上这个图标**
  - **第二步 · 分**：把草拖到对应的木牍上 → 归位、发光、语音念一句（"这株能治病"）
  - **没尝过就放**：草上冒出一个问号，自己飞回嘴边先尝一口 —— 不判错、不惩罚（零失败）
- **结局**：6 株分完 → 木牍上的图形一片片亮起，拼成最早的"药书" → 田里，喝了药汤的人站起来 → 语音："他尝过的苦，别人就不用再尝了。"
- **6 株草的内容提案**：谷穗、野果（能吃）；甘草（甜，止咳）、生姜（辣，驱寒）；毒蘑菇、不认识的蓝果子（有毒）
- **尺度**：毒草只让他皱眉头、脸发绿一下、头上冒金星，喝一口水就恢复；**不出现倒下、不出现死亡**（不提"神农尝断肠草而死"）
- **附加的安全教育**：不认识的野果 / 蘑菇不要吃 —— 这是可以带回现实的一条

### 3.2 大禹治水（`dayu`，模板：`tap`（堵）+ `trace`（疏），两段）

- **故事两幕**：① 洪水淹了田地，人们躲到山上；② 禹的父亲鲧用土去堵，堤越筑越高、九年不成。禹说："水往低处走，那就给它一条路。"
- **keyMoment**（beatId s2）："水这么大，怎么办？" → 给它一条流向大海的路（canonical）
- **玩法段一 · 堵**（复用 `tap`，画面外置，约 20 秒）：
  - 点一下 → 加一筐土，堤高一寸；水位跟着涨（**涨得比堤慢一点点**，所以看起来真的有用）
  - 点到第 10 下 → 水漫过堤顶 → **决口**（堤塌开一道口子，水冲回来，2 秒动画）
  - 语音旁白："堵得住一处，堵不住处处。" —— 零惩罚，紧接着就进下一段
- **玩法段二 · 疏**（新模板 `trace`，三段，约 90 秒）：
  - **段一「开一条沟」**：从决口划到第一处洼地（3 个锚点）
  - **段二「劈开龙门山」**：水被山拦住，划一条道穿过山口（完成时山裂开、水涌出）
  - **段三「送进大海」**：把水汇成一条，划到海边
  - 水沿着划出的线流动（水粒子），每完成一段：水位降一格、露出的土地上冒出绿苗
- **三过家门**（trace 的 `onSegmentDone` 里插三次，各 1.5 秒）：每段结束时路过一次家门口，窗里亮着灯、妻子抱着孩子 —— 他都没有进去。孩子可以点那扇窗（看一眼睡着的孩子），不点也不影响；**不阻塞、不扣分**
- **结局**：洪水入海、水落石出，田里长满绿苗，山上的人走下来 → 语音："十三年，他把水送回了大海。"
- **教学点**：堵不如疏；父亲失败的办法也是经验（不提"鲧被杀"，只提"九年不成"）

### 3.3 太公钓鱼（`taigong`，模板：`wait`，一屏）

- **故事两幕**：① 商朝末年，有位很有本事的老人，头发都白了，还没有人用他；② 他在渭水边钓鱼：钩是直的，没有鱼饵，还离水三尺。有人笑他，他说"愿者上钩"。
- **keyMoment**（beatId s2）："他为什么不用弯钩、不放鱼饵？" → 他要钓的不是鱼（canonical）
- **玩法**（一屏渭水，约 45 秒；autoplay 下 6 秒）：
  - 石头上坐着老人，直钩悬在水面**之上**；水下的鱼群游来游去，**永远不咬钩**（这是"直钩"的视觉证据）
  - 太阳在画面上方慢慢走，就是进度条；文王的车马从很远的天边一点点靠近
  - **诱惑**（换弯钩 / 加鱼饵 / 换地方）：点了老人会做那个动作、日影**退回一点**（+5 秒，最多退 3 次，保证不卡死），并说一句："我要钓的，不是鱼。" 孩子自己会发现"点这些没有用"
  - **陪着等的支线**（不影响进度，让等待不闷）：点水面 → 鱼群散开又聚拢；点云 → 云换个形状；点老人 → 他说一句（`lines` 里轮着来，语音）
  - **收束动作**：车马停下、文王下车时，小手出现在鱼竿上 = 把直钩收起来；点一下 → 收线、站起 → 文王开口："我祖父说过，会有圣人到周国来。" → 请他上车
- **结局**：车马远去，水面恢复平静，直钩留在石头上 → 语音："他等了很多年，等的是一个值得等的人。"
- **教学点**：等值得等的东西；不因为眼前的小鱼改自己的主意（不将就）
- **迁移题提案**：想钓一条大鱼，可小鱼一条接一条上钩 —— 你会？（放回去，接着等大鱼 ✓）

### 3.4 烽火戏诸侯（`fenghuo`，游戏专属场景 `beacon`）

- **故事两幕**：① 西边山上有一座座烽火台，点起来，天边的诸侯就会赶来救王；② 周幽王有位王后叫褒姒，怎么都不笑。有一天，他点起了烽火。
- **keyMoment**（beatId s2）："没有敌人，却点起烽火，会怎么样？" → 他们会赶来，然后笑起来（事实）；揭晓语："烽火是给敌人用的。用它开玩笑，第一次很好笑，第四次就没人来了。"
- **玩法**（一屏夜景，约 60 秒，**3 次推进 + 1 次真的**）：
  - 城楼上坐着一盏灯一样安静的褒姒；城角一条**信任条**（三格）
  - **第 1 次点睛火**：火光一柱柱亮起、一座座传向天边（1.5 秒接力动画）→ 四方诸侯的兵马赶来 → 到城下才发现没有敌人 → **褒姒笑了**（星光、花瓣、笑声）→ 信任 −1
  - **第 2 次**：来的兵马少了一半，走的时候有人在摇头 → 信任 −1
  - **第 3 次**：信任条空了 —— 火光还是传了出去，**远处的兵马停下来，掉头回去了，没有一个人到城下** → 语音："这次，他们连城门都没到。"
  - **第 4 次是真的**（剧情推进，不是玩家选择）：天边真的起烟尘 —— 点烽火 → 光一柱柱传到天边 → **什么也没有回来**（画面安静 2 秒，只有火在烧）→ 天亮，空荡荡的城楼
- **结局**：夜里的火一格格灭掉 → 语音："点起来的火是真的，喊来的兵是真的，只有那句'有敌人'是假的。信，用一次少一次。"
- **关键设计**：**孩子亲手把信任点完** —— 每一次都因为"她笑了"而按下，全篇没有一句说教文字
- **尺度**：犬戎来犯只画烟尘与火把剪影，**不画刀兵、不画死亡**；褒姒全程被善待
- **史实与史观（重要）**：
  - 出处写《史记·周本纪》；同时注明"**后世学者（清华简《系年》、钱穆等）多认为'烽火戏诸侯'未必是史实**"
  - 教训落在**信用**上，不落在褒姒身上；结局旁白明确"错在点火的人"
  - 与"狼来了"同构：这是孩子最容易迁移的一条

### 3.5 杞人忧天（`qiren`，模板：`place`，复用）

- **故事两幕**：① 杞国有个人，担心天会塌下来、地会陷下去，愁得吃不下饭、睡不着觉；② 有人来看他，告诉他：天，是积起来的气；地，是积起来的土。
- **keyMoment**（beatId s1）："天真的会塌下来吗？" → 天是积起来的气，不会塌（canonical）
- **玩法**（一屏夜景小屋，复用 `place`，约 60 秒）：
  - 他头顶飘着 **4 个担忧泡泡**：天塌 / 地陷 / 日月会掉 / 星星会坠
  - 底部 **4 个"想明白"的光球**，画成具体的东西：一团气（呼出来就能看见）、一块土、日月、一颗小石子（流星）
  - 拖光球 → 对上泡泡 → 泡泡里演一小段"看一看"：气托着鸟和云 / 跺一跺脚土地稳稳的 / 太阳落下第二天又升起来 / 流星掉下来只是小石子，落在手心里
  - 泡泡"啵"地破掉 → 屋里亮一点 → 语音念原文的白话（"天，是积起来的气。"）
  - 零失败：拿起来时对的泡泡发光（沿用 place 的做法）
- **结局**：四个泡泡都破了 → 头顶的黑云散开，他长长舒一口气 → 躺下睡着 → 星空安静地转 → 语音："他不是傻，他只是还没想明白。想明白了，就能睡了。"
- **教学点**：怕，是因为还没想明白；想明白的人不笑他（原文"晓之者亦舍然大喜"）—— 这则寓言**不是**用来嘲笑杞人的
- **迁移题提案**：下面哪一个是"想明白了就不怕"？→ 怕黑，就把灯打开看一看（房间还是原来那样）✓

| **大禹"堵"的失败让孩子挫败** | 只 10 下；溃堤是"水冲回来"的动画，不是"你输了"；旁白只陈述事实；紧接着立刻给"疏"的玩法 |
| **神农尝毒草吓到小朋友** | 只皱眉、脸发绿一下、冒金星，喝口水就恢复；不出现倒下/死亡；落点改成"记下来，别人就不用尝"，外加"不认识的野果和蘑菇不要吃" |
| **3 个新模板，回归风险** | 每个模板先落地、单测、跑通再叠游戏；模板只做循环与判定，画面 100% 外置（沿用 tap 的做法）；每批结束全量回归 |

| **trace 依赖指针采样，慢机器上点稀疏** | 判定只看锚点顺序与容差（半径 60+），不做像素比对；采样间距只用于防"瞬移"，阈值放到宽松 |
| **五部一起做，战线太长** | 分三批，每批都有可玩的成品与独立验收 |
