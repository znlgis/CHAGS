# 三十六计 · 第三辑（攻战计 13–18）方案

> 依据：[三十六计方案.md](三十六计方案.md)（总方案，已确认）。
> 本辑交付 **第 13–18 计、6 个游戏**：新增 **3 个模板**（`probe` / `lure` / `chase`）
> + **扩展 1 个**（`borrow` 加 `banner` 模式，借尸还魂）—— 与总方案第五节一致，无修正。

## 〇、硬约束（与前两辑相同）

1. **纯判定与画面分家**：判定放 `<模板>.logic.ts`（不许 import Phaser），场景只喂墙钟；
   `<模板>.logic.test.ts` 覆盖正常路径、失败路径、零惩罚重来、边界。
2. **每个模板必须实现 `runAutoplay()`**，走**与真实操作同一条**路径。
3. **零惩罚**：惊动了蛇、被看守抓回来、跟丢、配对不成 —— 都只是退回与重来，不扣星、不结束。
4. **扩展不许碰老模式**：`borrow` 的 `force` 分支（第 3 计 借刀杀人，已上线）一行都不许改，
   既有 10 项判定单测必须原样全绿 —— 与第二辑对 `window` 的要求一样。
5. **模板常量放模板自己文件里**；**引文口径**：逐字确证不了的史源原文不编，用《三十六计》本计按语。
6. **儿童化**：不出现流血死亡；**第 18 计"擒王"是找到那个人（不是伤害他）**；
   第 16 计的"擒"落在"让他心服"，不是把人抓住。

## 一、三个新模板 + 一个扩展

### 1. `probe` 试探（13 打草惊蛇 · knock / 18 擒贼擒王 · spot）

两个模式共用一句话：**用一枝没有杀伤的"试探"，换来信息**。

**knock（打草惊蛇）**：路上几处草丛，一处一处敲过去 —— 敲到有蛇的那一处，蛇会窜出来，
**把附近的草丛一起搅乱**（那些地方就不能走了）。找到一处"确认安全"的草丛走过去即可。

| 字段 | 说明 |
|---|---|
| `patches[]` | `{id, x, y, radius, has: 'snake' | 'clear'}`，4–6 处 |
| `scareRadius` | 敲到蛇时，这个距离内的草丛一起被搅乱（**这就是"打草"的代价**） |
| `exit` | `{x, y, radius}`：确认安全之后走到这里 |

判定：`probeAt(level,x,y)`、`knock(level,state,patchId)`（记录已敲 + 若是有蛇则算 spooked 集合）、
`isSpooked(state,id)`、`canCross(level,state,id)`（**敲过且确认没有蛇、且没被搅乱**）、
`cross(level,state,id)`、`isKnockDone(state)`。
**schema refine**：至少有一处 `clear` 的草丛不在任何蛇的 `scareRadius` 内（否则可能无解）。

**spot（擒贼擒王）**：一排一模一样的身影，其中**恰好一个是王**。
拿蒿箭一个个试过去：射中不是王的，他会退到一边（少一个候选）；射中王的，他会有反应 —— 就是他。

| 字段 | 说明 |
|---|---|
| `figures[]` | `{id, x, y, radius, isKing}`，5–7 个，恰好一个王 |
| `arrows` | 候选人数（= figures.length，够用即可） |

判定：`shoot(level,state,figureId)`（射中王 → 完成；射中不是王的 → 标记 `tried`）、
`isFigureTried`、`remainingFigures`、`isSpotDone(state)`。
**schema refine**：恰好一个 `isKing`、figures ≥ 3。

### 2. `lure` 诱饵（15 调虎离山 · decoy / 17 抛砖引玉 · trade）

**decoy（调虎离山）**：看守站在岗位上。把诱饵放到某个诱饵点，他会走过去看（岗位空出一段时间）；
趁这段空档把东西拿走 —— 拿东西要**连续**的空档时间，看守一回来，没拿完的就白拿（零惩罚）。

| 字段 | 说明 |
|---|---|
| `guard` | `{x, y, radius}` 岗位 |
| `baits[]` | `{id, x, y, radius, awayMs}`：放这里能让岗位空多久 |
| `prize` | `{x, y, radius, needMs}`：要连续多长的空档才拿得走 |

判定：`placeBait(level,state,baitId,t)`、`awayLeftMs(level,state,t)`、`grabAt(level,state,t)`（空档内累计）、
`guardBack(level,state,t)`（回岗：没拿完的清零）、`isDecoyDone(level,state)`。
**schema refine**：至少有一个 bait 的 `awayMs ≥ prize.needMs`（否则这一关不可能过）。

**trade（抛砖引玉）**：先给出一块"砖"，对方拿出更好的来换；挑对了才有"玉"。

| 字段 | 说明 |
|---|---|
| `partner` | `{x, y}` 对方在哪儿 |
| `offers[]` | `{id, x, y, radius, kind}` 你手里的"砖" |
| `returns[]` | `{offerId, kind, value}` 对方会还回来的东西 |
| `needed` | 换到 `value ≥ needed` 算成 |

判定：`offerFor(level,offerId)`、`give(level,state,offerId)`（记下换到了什么）、`isTradeDone(level,state)`。
**schema refine**：`returns` 覆盖每一个 `offer`；至少一个 `value ≥ needed`。

### 3. `chase` 追而不逼（16 欲擒故纵）

**机制**：**按住追**，距离缩短；**松手**，距离拉开。距离要待在一个区间里：
太近（< `keepMin`）对方反抗、体力回涨；太远（> `keepMax`）就跟丢、白追一段。
距离在区间内时，对方的体力持续下降 —— 体力见底 = 他心服。

| 字段 | 说明 |
|---|---|
| `keepMin` / `keepMax` | 要维持的距离区间（0–100） |
| `start` | `{distance, stamina}` 开局 |
| `closePerSec` / `farPerSec` | 按住缩得多快、松手拉得多快 |
| `drainPerSec` | 在区间内时，对方体力每秒掉多少 |
| `recoverPerSec` | 逼太近时，体力每秒回多少 |
| `losePerSec` | 跟丢时，这段追逐的进度每秒退多少 |
| `hold` | `{x, y, radius}` 按住这里 |

判定：`chaseStart(level)`、`tick(level,state,dtMs,holding)`、
`distanceBand(level,state)` → `'tooClose' | 'good' | 'tooFar'`、`isChaseDone(level,state)`。
**schema refine**：`keepMin < keepMax`、`drainPerSec > 0`、`recoverPerSec < drainPerSec`（否则逼太近不痛不痒）。

### 4. `borrow` 扩展：`banner` 模式（14 借尸还魂）

**机制**：一面倒下的旧旗 + 散落的人。把旗竖起来 —— 旗能召回多少人写在旗上（`rally`）；
召不够就换一面旗继续（零惩罚）。旗就是"名号"：**一个响亮的名号能把人聚起来**。

| 新增 | 说明 |
|---|---|
| `mode: 'banner'` | 与 `'force'` 并列 |
| `pole` | `{x, y, radius}` 旗杆：把旗拖到这里竖起来 |
| `flags[]` | `{id, x, y, radius, rally}` 可用的旗 |
| `scattered[]` | `{id, x, y, radius}` 散落的人（4–8 个） |
| `needed` | 召回几个算成 |

判定：`raiseFlag(level,state,flagId)`（每面旗只能用一次，返回召回人数）、`ralliedCount(state)`、
`isBannerDone(level,state)`。**schema refine**：所有旗的 `rally` 之和 ≥ `needed`（否则无解）、
`needed ≤ scattered.length`。**`force` 模式的行为与判定一个字都不改。**

## 二、六个游戏

### 第 13 计 · 打草惊蛇 `dacao-jingshe`（probe · knock）

- 史源：王鲁"打草惊蛇"（《南唐近事》，成语出处）。
  `source`: 《三十六计·攻战计》/打草惊蛇/`'疑以叩实，察而后动。复者，阴之媒也。'`
- pinyin `Dǎ cǎo jīng shé`；五代（`yearApprox: 940`）；figures `['王鲁']`
- moral：`先试一试，再动手 —— 但试本身也会惊动别人。`
- keywords `['试探','看反应','先想再动']`；ageRange `[8,12]`
- 故事：`s1` 案卷上出现了自己的名字，王鲁心里发慌；`s2` 他拿竹竿拨开草丛 —— 蛇一窜，全院子都知道了。
- keyMoment（`s1`）："想知道草丛里有什么，又不想让所有人都知道，怎么办？" →
  **先轻轻拨一处，看清楚再说**（canonical）/ 把整片草都踩平 / 不管它直接走
- quiz：记忆题（成语"打草惊蛇"里的"惊"惊动了谁）；迁移题"想知道抽屉里有没有东西"→
  先轻轻拉开一条缝看一眼，别整个倒出来。
- 关卡：5 处草丛（2 处有蛇），`scareRadius: 150`、exit 在右侧；数据要保证有一处 clear 不被任何蛇覆盖。
- 画面：一条小路 + 五丛草，敲一处起一圈草浪；敲到蛇 → 蛇探头 + 邻近草丛塌下去。

### 第 14 计 · 借尸还魂 `jieshi-huanhun`（borrow · banner）

- 史源：陈胜吴广借扶苏、项燕之名起兵（《史记·陈涉世家》）。
  `source`: 《三十六计·攻战计》/借尸还魂/`'有用者，不可借；不能用者，求借。'`
- pinyin `Jiè shī huán hún`；秦末（`yearApprox: -209`）；figures `['陈胜','吴广']`
- moral：`一个响亮的名号，能把散掉的人重新聚起来。`
- keywords `['名号','聚人','旧旗']`；ageRange `[8,12]`
- 故事：`s1` 队伍散了，只剩一面旧旗；`s2` 旧旗一竖，四面八方的脚步声回来了。
- keyMoment（`s1`）："人都散了，怎么把人叫回来？" → **把旧旗竖起来**（canonical）/ 一个个去追 / 算了
- quiz：记忆题（陈胜吴广借的是谁的名号）；迁移题"想组织一场班级活动，没人理你"→
  借一个大家都认的名头（比如"校运会班级队"）来召集。
- 儿童化：**"尸"字出现在计名里**（保留），但画面上没有尸体 —— 只有一面旧旗与散落的人。
- 关卡：`pole` 中央；3 面旗 `rally` 2/3/4；6 个散人；`needed: 6`（牌面：2+4 或 3+4）。
- 画面：黄昏的空地、一面倒下的旧旗、三面可用的旗插在地上、散落的人影。

### 第 15 计 · 调虎离山 `diaohu-lishan`（lure · decoy）

- 史源：孙策诱刘勋取庐江（《三国志·吴书·孙策传》注引《江表传》）。
  `source`: 《三十六计·攻战计》/调虎离山/`'待天以困之，用人以诱之。往蹇来连。'`
- pinyin `Diào hǔ lí shān`；东汉末（`yearApprox: 199`）；figures `['孙策','刘勋']`
- moral：`把他引开，路就通了。`
- keywords `['诱饵','空档','引开']`；ageRange `[8,12]`
- 故事：`s1` 山口的守将一步不离；`s2` 山那边闹起来了，守将过去看 —— 山口空了。
- keyMoment（`s1`）："守将一直站在山口，怎么过去？" → **在山那边放个诱饵，把他引开**（canonical）/
  硬冲过去 / 等他自己走
- quiz：记忆题（守将为什么离开了山口）；迁移题"妈妈一直守在厨房门口"→
  让她去接个电话，趁空档把碗端出去。
- 关卡：`guard` 山口 `(375, 520, 96)`；3 个诱饵点 `awayMs` 3200 / 5200 / 7000；
  `prize` `(560, 1000, 100)`，`needMs: 4800` → 只能用后两个诱饵点（教学点：**要挑能空够久的那个**）。
- 画面：一座山口、一个守将、山那边的炊烟与灯火、山脚要拿的箱子。

### 第 16 计 · 欲擒故纵 `yuqin-guzong`（chase）

- 史源：七擒孟获（《华阳国志·南中志》）。
  `source`: 《三十六计·攻战计》/欲擒故纵/`'逼则反兵，走则减势。紧随勿迫，累其气力，消其斗志，散而后擒。'`
- pinyin `Yù qín gù zòng`；三国（`yearApprox: 225`）；figures `['诸葛亮','孟获']`
- moral：`逼急了会反抗，松一点反而成。`
- keywords `['追','保持距离','让他心服']`；ageRange `[9,12]`
- 故事：`s1` 追得太紧，前面的人回头就要打；`s2` 他松了松绳子，前面的人自己慢了下来。
- keyMoment（`s1`）："他一直跑，怎么才能让他停下来？" →
  **跟住但别逼太近，等他没力气**（canonical）/ 冲上去一把抓住 / 不追了
- quiz：记忆题（追的时候要保持在什么距离）；迁移题"小猫躲在沙发底下不肯出来"→
  蹲在不远处等它自己出来，别伸手去抓。
- 关卡：`start {distance: 70, stamina: 100}`、`keepMin: 34`、`keepMax: 70`、
  `closePerSec: 16`、`farPerSec: 12`、`drainPerSec: 7`、`recoverPerSec: 4`、`losePerSec: 5`、`hold` 按钮在下方。
- 画面：一条山道，两个人影一前一后；中间一条"距离"刻度（区间用绿色标出来），
  上方对方体力条；逼太近 → 对方回头（红闪）；跟丢 → 人影变小、进度退。

### 第 17 计 · 抛砖引玉 `paozhuan-yinyu`（lure · trade）

- 史源：常建题诗引赵嘏续成（《唐才子传》，文人典故）。
  `source`: 《三十六计·攻战计》/抛砖引玉/`'类以诱之，击蒙也。'`
- pinyin `Pāo zhuān yǐn yù`；唐（`yearApprox: 800`）；figures `['常建','赵嘏']`
- moral：`先给一点点，换来更好的 —— 关键是挑对那块"砖"。`
- keywords `['先给','换来','挑对']`；ageRange `[9,12]`
- 故事：`s1` 墙上只有两句诗，没人接着写；`s2` 常建先写下两句，路过的人看见，补出了后面的好句。
- keyMoment（`s1`）："想让别人写出更好的句子，怎么办？" →
  **先在墙上写下自己那两句**（canonical）/ 等别人先写 / 把墙刷白
- quiz：记忆题（常建先做了什么）；迁移题"想让同学一起玩你的积木"→
  先拿出自己的两块搭个样子，别人就会带着更多来。
- 关卡：`offers` 三块砖（kind: paper / ink / brush），`returns` 对应 value 2 / 3 / 6，`needed: 6`。
  教学点：最不起眼的那块（纸）反而换回最多。
- 画面：书斋墙、三样可以递出去的东西、对方的反应（拿出什么）。

### 第 18 计 · 擒贼擒王 `qinzei-qinwang`（probe · spot）

- 史源：张巡蒿箭射尹子奇（《旧唐书·张巡传》）—— 用没有杀伤的蒿箭试出敌将。
  `source`: 《三十六计·攻战计》/擒贼擒王/`'摧其坚，夺其魁，以解其体。'`
- pinyin `Qín zéi qín wáng`；唐·安史之乱（`yearApprox: 757`）；figures `['张巡','尹子奇']`
- moral：`一群人里，先找出最关键的那一个。`
- keywords `['找关键','试探','看反应']`；ageRange `[9,12]`
- 故事：`s1` 对面一排人，穿得一模一样；`s2` 一枝蒿箭射过去，那个回头喝令的人 —— 就是他。
- keyMoment（`s1`）："怎么在一群一模一样的人里找到领头的？" →
  **用一枝没有杀伤的箭试，看谁的反应最大**（canonical）/ 一个个抓过来问 / 随便猜一个
- quiz：记忆题（张巡用什么射过去）；迁移题"一群同学在操场上吵闹"→
  先看谁一开口大家就安静（那个人是领头的）。
- 儿童化：**蒿箭是"没有杀伤的箭"**（史源如此），射中人只是让他退到一边；
  揭晓语落在"找出关键的那一个"，不是"打倒他"。
- 关卡：6 个身影（1 个王），蒿箭充足。

**三条实现上的判断（都由实现分支提出、Lead 采纳）**：

1. **`probe.knock` 的"存在解"要能被穷举证明**：单测对 5 丛数据跑完**全部 120 种敲击顺序**，
   断言每一步之后都还有可走的草丛（唯一安全的那一丛永远搅不乱）——"打草"的代价不能变成"必输"。
2. **`lure.decoy` 的"连续空档"**：按住箱子才记账、松手或挪开就断（幂等），看守回岗清零但可以再来；
   `placeBait` 只在看守在岗时生效 —— 否则连点就能把空档无限续下去。
3. **`chase` 的自动通关与真实按住走同一个 `this.holding`**：`holdWanted()` 只是"什么时候按/松"的策略，
   与孩子的手指没有第二条路径 —— 与 stillness / window 一脉相承。
