## 〇、硬约束（与第一辑相同，写代码前先看）

1. **纯判定与画面分家**：判定放 `<模板>.logic.ts`（不许 import Phaser / @chags/phaser-kit），
   场景只喂墙钟；`<模板>.logic.test.ts` 覆盖正常路径、失败路径、零惩罚重来、边界。
2. **每个模板必须实现 `runAutoplay()`**，且走**与真实操作同一条**路径（不是另写一条自动分支）。
3. **零惩罚**：看错、被看穿、错过机会、配对输一局 —— 都只是重来或代价，不扣星、不结束。
4. **模板常量放模板自己文件里**（`export const SHOW = {...}`），不要挤进 `layout.ts`。
5. **儿童化**：不出现流血死亡；第 10 计**只教"识破"**（不教怎么使笑里藏刀）；

6. **引文口径**：逐字确证不了的史源原文不编，改用《三十六计》本计按语（`source.book = 《三十六计·敌战计》`）。

## 一、四个新模板 + 一个扩展

### 1. `show` 造势（第 7 计 无中生有 · draw）

**机制**：从**什么都没有**开始，在城墙/船帮的**空位**上一笔笔画影子；画出来的影子会**淡掉**，
所以要不停补笔。同时立着的影子够 `needed` 个，对方的"疑心"才涨；不够时疑心缓慢回落。
疑心到 `goal` 就算成 —— 这一计的本体不是点一下，而是**维持一个不存在的东西**。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'draw'`（第 29 计树上开花以后再加 `borrow`） |
| `slots[]` | `{id, x, y, radius}`：可以画影子的空位（3–8 个） |
| `fadeMs` | 一笔能立多久，到点就淡掉 |
| `needed` | 同时立着的影子数达到它，疑心才涨 |
| `goal` | 疑心涨到多少算成功 |

判定：`showStart()`、`paint(state, slotId, t)`、`aliveShadows(level, state, t)`、
`beliefAt(level, state, t)`、`tick(level, state, t, deltaMs)`、`isShowDone(level, state)`。
**schema refine**：`needed ≤ slots.length`、slots id 不重。

### 2. `twoline` 双线（第 8 计 暗度陈仓 · stack）

**机制**：两条进度线。**明线**（修栈道）会随时间长回落，点一下补一截 —— 只要不低于
`minKeep` 就不会被看穿；**暗线**（走小路）点一下推一截，到 `goal` 就成。
两条线抢同一根手指：只顾明线推不动暗线，只顾暗线会被看穿。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'stack'`（第 33 计反间计以后再加 `plant`） |
| `decoy` | `{x, y, radius, decayPerSec, topUp, minKeep}` 明线 |
| `real` | `{x, y, radius, step, goal}` 暗线 |

判定：`twolineStart()`、`decoyNow(level, state, t)`、`tapDecoy(level, state, t)`、
`tapReal(level, state, t)`、`isExposed(level, state, t)`（明线跌破 minKeep）、`isTwolineDone`。
被看穿 = 明线立刻补回 `minKeep`、记一次 `exposed`，**不结束**。

### 3. `read` 识破（第 10 计 笑里藏刀 · inspect）

**机制**：对方满口好话，但每隔一会儿会露出一个**破绽**（眼神飘一下、袖口动一下）——
每个破绽只在 `windowMs` 内可见，点中就算"看穿"；没有破绽的时候点，只是没收获（零惩罚）。
看穿 `goal` 个破绽 = 看懂了他真正的打算。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'inspect'`（单模式，后续不扩） |
| `speaker` | `{x, y}`：说话的那一位 |
| `tells[]` | `{id, atMs, windowMs, x, y, radius, kind}`：破绽出现的时刻与位置 |
| `goal` | 看穿几个算看懂 |

判定：`tellAt(level, t)`、`tellsSoFar(level, t)`、`applyRead(level, state, tellId)`、
`isReadDone(level, state)`、`readMisses(state)`。
**schema refine**：`atMs` 递增、`goal ≤ tells.length`、id 不重。

### 4. `matchup` 配对编排（第 11 计 李代桃僵 · pair）

**机制**：你有三匹马（上/中/下），对面三场（整体更强）。把它们**配对**好，再开赛；
三局两胜即胜。用下驷对上驷是**故意舍一局** —— 这一计的落点就在这儿。

| 字段 | 说明 |
|---|---|
| `mode` | 本辑只有 `'pair'`（第 23 计远交近攻以后再加 `order`） |
| `horses[]` | `{id, rank: 'top'|'mid'|'low', power, x, y, radius}`，恰好三匹、rank 各一 |
| `rivals[]` | `{id, power, x, y, label}`，恰好三场 |
| `needWins` | 赢几场算胜（本辑 = 2） |

判定：`pairings(level)`（3! = 6 种全枚举）、`resolve(level, roster)` → 每场 `{rivalId, horseId, win}`、
`winsFor(level, roster)`、`bestRoster(level)`、`isMatchupDone(level, wins)`。
**schema refine**：三个 rank 各一、`bestWins ≥ needWins`（否则这一关不可能赢）。

### 5. `window` 扩展：`glimpse` 模式（第 12 计 顺手牵羊）

**机制**：队伍沿路前进（这一趟总共 `travelMs`）；路上**每隔一轮出现一个机会**，
只在那一轮的窗口里抓得住（点够 `workMs`）；错过就过去了。抓够 `goal` 件算成；
一趟走完没抓够 → 重走一遍（零惩罚）。

**对既有模板的最小扩展**（其余逻辑完全复用）：

| 新增 | 说明 |
|---|---|
| `mode: 'glimpse'` | 与 `'fire'` 并列 |
| `travelMs?` | glimpse 必填：这一趟的总时长 |
| `currentJob(level, t)` | glimpse：这一轮只放出一件机会（`jobs[cycle % jobs.length]`） |

**schema refine**：`mode === 'glimpse'` ⇒ `travelMs` 必填；`fire` ⇒ 不许写 `travelMs`。

### 6. `wait` 复用（第 9 计 隔岸观火）

不需要新增字段：`temptations` 就是"出手调解"（点一次把终点往后推），`lines` 是那句劝架的话，
`finale` 是"等他们自己乱完"的收束动作。**只有在游戏侧需要新画**（两拨人吵架 → 慢慢自己散开）。

### 第 7 计 · 无中生有 `wuzhong-shengyou`（show · draw）

- 童年视角的史源：**草船借箭**（《三国演义》第四十六回，演义）。
  `source`: 《三十六计·敌战计》/无中生有/`'诳也，非诳也，实其所诳也。'`
- pinyin `Wú zhōng shēng yǒu`；三国（`yearApprox: 208`）；figures `['诸葛亮','鲁肃']`
- moral：`没有的东西，可以先画出来，把它站住。`
- keywords `['从无到有','影子','撑住']`；ageRange `[8,12]`
- 故事：`s1` 江上大雾，船上空空的；`s2` 一排草人在雾里立起来，对面的箭像雨一样飞来。
- keyMoment（`s2`）："船上什么都没有，怎么让对面以为有人？" → **在空位上把草人一个个立起来**（canonical）/
  大声喊话 / 掉头回去
- quiz：记忆题（诸葛亮让什么立在船上）；迁移题"想让空教室看起来有人，怎么做"→ 把书包和水杯摆在座位上。
- 关卡：6 个空位（船帮一排），`fadeMs: 4200`、`needed: 4`、`goal: 100`（疑心涨满）。
- 儿童化：雾里的箭射在草人上，没有人受伤。

### 第 10 计 · 笑里藏刀 `xiaoli-cangdao`（read · inspect）

**两条实现上的决定，值得记住**（都由实现分支主动提出、Lead 采纳）：

1. **`glimpse` 的"一趟"是时间预算**：`travelMs` 走完就回到起点重走，抓到的留着、半截清零 ——
   重走**不扣星、不结束**（零惩罚），这样"错过"才有代价而不变成惩罚。
2. **`matchup` 的`相等算输`**：`power` 相等时判输，写进了注释与单测 ——
   田忌赛马里"差一点"就是差一点，这个规则要明确，不能靠实现者的直觉。

**一处产品口径修正（复看截图时发现）**：`wait` 模板原来只接受 `titleKey`（文案键），
于是隔岸观火的顶栏显示的是场景动词"等一等"，而三十六计其它计显示的是**计名**。
改成 `title?: string` 与 `titleKey?` 二选一（向后兼容），隔岸观火改传 `ctx.content.title`；
太公钓鱼仍走 `titleKey: 'scene.wait'`，它的两条 e2e 用例重跑无回归。
